# IBM 黑客松專案

## 團隊簡介
本專案為 IBM Skills Build 黑客松一日 MVP 作品，由 6 人混齡團隊共同完成。

## 專案目標
打造具社會影響力的 MVP，解決真實存在的社會問題。

## 團隊分工
| 角色 | 負責人 | 主要產出 |
|------|--------|---------|
| 技術開發 | - | MVP 前端介面、核心邏輯 |
| 內容與研究 | - | 問題背景文件、用戶故事 |
| 視覺設計 | amy-0919 | 配色方案、介面草稿、品牌識別 |
| 簡報 + 說故事 | - | 評審簡報、Demo 腳本 |

## 如何執行
開啟 `index.html` 即可在瀏覽器中查看專案。
